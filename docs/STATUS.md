## Meaningful limitations

A covered Below body can make its only menu inaccessible. Accepted local Show restores a genuinely minimized body but cannot raise an already visible Below body. Show preserves effective Above/Normal/Below layer, not exact relative z-order among Normal-layer peers: Openbox raised a locally restored body in H09 through its own presentation behavior, with no explicit DesktopRoomie stack/activation request. This is not Bring Top, which remains unsupported. Finite duration provides an exit fallback. Workspace changes suspend/cancel interaction rather than moving the body to follow the user. Monitor identity is retained; removal is an error, not automatic migration.

Layer confirmation establishes readable EWMH flags, not visual stacking or who caused a change. A partial transition can leave Normal; there is no rollback or reassertion loop. Finite operation deadlines assume a responsive X server and do not impose hard transport timeouts on synchronous replies. Brain/Spine, runtime memory/services, animation assets, persistence and cross-device abstractions are not implemented.
