## Meaningful limitations

A covered Below body can make its only menu inaccessible. Accepted local Show restores a genuinely minimized body but cannot raise an already visible Below body. Show preserves effective Above/Normal/Below layer, not exact relative z-order among Normal-layer peers: Openbox raised a locally restored body in H09 through its own presentation behavior, with no explicit DesktopRoomie stack/activation request. This is not an explicit Bring Top request. Accepted Bring Top confirms the EWMH Above layer only, not absolute peer ordering or precedence over fullscreen. Finite duration provides an exit fallback. Ordinary workspace changes suspend/cancel interaction rather than automatically following the user; public `--bring-here` is a separate explicit caller-requested relocation. Monitor identity is retained; removal is an error, not automatic migration.

Layer confirmation establishes readable EWMH flags, not visual stacking or who caused a change. A partial transition can leave Normal; there is no rollback or reassertion loop. Finite operation deadlines assume a responsive X server and do not impose hard transport timeouts on synchronous replies. Brain/Spine, runtime memory/services, animation assets, persistence and cross-device abstractions are not implemented. See [ARCHITECTURE](ARCHITECTURE.md) and [INDEX](INDEX.md) for source boundaries and deeper evidence.
