## Accepted public Recover contract

A single `Command::Recover` retains one active owner slot and request correlation through a one-way Here→Top handoff. The caller captures the frozen workspace before owner discovery and sends once using the existing v2 protocol, with **9000 ms** immutable caller budget. The owner has **7000 ms** total: Here up to **3500 ms**, Top visibility **2500 ms** from actual validated handoff, layer up to **1000 ms** after admission, all capped by the original total. No handoff, event, duplicate, delayed scheduling or retry renews authority.

Here current proof is invalidated at handoff while immutable destination/monitor/body identity, original baseline, independently confirmed relocation/restoration history, possible dispatch, and consumed authority remain intact. There is **one correction allowance** across Here and Top, with a full **150 ms** correction confirmation requirement. Top reuses accepted Show/input-fence handling and the sole absolute Above `LayerController`. Strict frozen destination/count/workarea/viewport/monitor/body-size checks guard mutations, including between user-time and MapWindow and between layer removal/addition. Native acknowledgement or an already-ready no-op never fabricates restoration/relocation history.

Success requires fresh same-body, frozen-workspace, not-minimized, effective Above, fixed-size placement and safe input evidence without focus activation or user workspace switch. An incomplete current postcondition is Partial **only** with confirmed historical relocation/restoration; otherwise Failed. Native failures enter one D4.1-derived fatal policy, clear current proof, preserve original error and genuine history, safely re-fence and attempt at most one correlated terminal response. Caller OutcomeUnknown does not resend or infer a terminal result. Existing independent commands retain their accepted meaning.

Deterministic source tests cover handoff/cutoff/correction cross-products, each mutation veto, evidence drift/invalid layout, uncertain checked dispatch, fatal errors inside and outside scheduling before/after each phase, shutdown/ownership, caller death/reply loss/Unknown, single Busy owner, >64-event traffic and legacy-command regressions. These tests do **not** constitute host reproduction of those injected failures.

### Test-harness, identity and qualification notes

- Before the N13 host reboot the body XID was `0x3800002`; after reboot it was `0x3600002`. After later Quit/relaunch the numerical XID was again `0x3600002`: an XID can be reused by a new process and **is not evidence the prior owner survived**.
- The **first N13 test harness was invalid**, because a zsh array named `commands` collided with a special parameter and inadvertently spawned runaway shell jobs. The owner rebooted to clear the jobs. The truncated initial N13 log is inconclusive, **not an application failure**. A corrected Bash harness launched exactly eight bounded callers and passed. N14 independently established actual Busy arbitration, not N13.
- N14's seven Busy replies were Preflight rejections, not failures of the successful Recover; N15 demonstrated subsequent admission. N16's nonzero code was expected.
- The owner reported no flicker and intact responsiveness during contention, and confirmed expected menu/drag behavior after N19. N19-C is a two-snapshot **state stability** observation, not a continuous trace proving no internal polling.
- N01–N19 denotes **19 numbered scenarios**; N18 has four cases and N19 includes popup, drag and passive subtests. Passed applies to the explicitly exercised assertions.

## Native boundaries and next gate

This acceptance is **host-qualified**, not a claim of exhaustive native failure injection. N10 was owner-observed dual-monitor retention, without a separate post-E4 RandR snapshot or deliberate monitor hot-plug. Genuine native WM refusal, corrupt root properties, changed workarea/viewport, monitor loss, synchronous native X11 faults, reply loss and on-host Partial/OutcomeUnknown were not deliberately induced; related behaviors are tested deterministically. Native off-workspace Iconic/no-HIDDEN and all exact boundary races were not repeated as separate E4 probes. Other WMs, Wayland, fullscreen stacking, or indefinitely stalled synchronous X11 replies remain unverified.

Quit/no-owner/relaunch passed N16–N17; **Stage-E-specific duration expiry, forced kill/relaunch and every cross-command lifecycle interleaving were not individually retested natively**, although earlier stages and injected tests address portions. These are evidence qualifications, not observed code defects.
