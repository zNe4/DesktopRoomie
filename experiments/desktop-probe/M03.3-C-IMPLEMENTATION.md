## Deadline, uncertainty and truth

`send_before(conn, deadline, &mut dispatched)` consumes its request, checks the logical deadline **before** `send_event`, and returns `Ok(false)` at expiry without mutation. If `send_event` fails before cookie acquisition, no dispatch evidence is added. Once a cookie is acquired, possible dispatch is marked **before** `cookie.check()`; a subsequent checked error retains that evidence. It never clears an already-set dispatch flag and never internally retries. This follows the established checked-send discipline and assumes a responsive synchronous X connection, not an independently enforceable X server timeout.

`Ok(true)` means only that the X request received checked transport completion; it does **not** confirm destination membership, preserved layer, minimization, geometry, input readiness, historical relocation, or command-level Success/Partial. The owner event loop has no Stage-C consumer, so there is no actual DesktopRoomie relocation in this revision.
